## 📋 Sobre o Projeto

O **consumo de agua** é um script interativo baseado em terminal que automatiza a triagem de consumo hídrico de diferentes tipos de imóveis (**comercial**, **casa** e **apartamento**). O programa aplica regras de negócio específicas para orientar a população sobre o uso consciente da água, ajudando a identificar desperdícios e vazamentos.

### 📊 Regras de Negócio Implementadas
* **Imóvel Comercial:** Aplica tarifa corporativa diferenciada.
* **Apartamento (< 10 m³):** Identifica consumo econômico (excelente controle).
* **Apartamento (qualquer consumo >= 10 m³) ou Casa (até 25 m³):** Classifica como consumo moderado (dentro do padrão residencial).
* **Demais casos:** Dispara alerta de consumo excessivo, recomendando verificação de vazamentos.

## 🚀 Como Executar o Programa

Certifique-se de ter o **Python** instalado em sua máquina.

1. Clone este repositório ou baixe o arquivo do código-fonte (`.py`):
   ```bash
   git clone https://github.com/alexandre82-pinheiro/consumo de água.git
   ```
2. Navegue até o diretório do projeto pelo terminal/prompt de comando.
3. Execute o script Python:
   ```bash
   python nome_do_arquivo.py
   ```
4. Siga as instruções interativas na tela informando o tipo de imóvel e o consumo mensal em $m^3$.
